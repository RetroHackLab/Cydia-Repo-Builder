🚀 How to Use

Follow these standard terminal steps to initialize and build your custom Cydia repository architecture:

  • Set Permissions: Grant executable privileges to your primary local management utilities: 
    chmod +x Projects.sh Packages.sh Update.sh github.sh
  • Scaffold Architecture: Run the main compiler pipeline to set up your metadata structures: 
    ./Projects.sh
  • Generate Runtime Compiler: Generate your localized database refresher script: 
    ./Update.sh
  • Index Tweaks: Place your compiled .deb packages inside the /debs directory and index them: 
    ./Packages.sh
  • Deploy Upstream: Run the isolated git tracker to push production files securely to GitHub Pages: 
    ./github.sh

🔍 Troubleshooting

Quick fixes for common setup errors and platform alignment anomalies:

❌ Error: Permission Denied

Your local terminal environment blocks the script launch. Resolve it by applying global execution flags: chmod +x *.sh.

❌ Error: \r: command not found (CRLF Issues)

Windows-style line endings break Unix script execution. Convert your configuration assets back to standard Unix format using: dos2unix *.sh.

❌ Error: Hash Sum Mismatch inside Cydia

The Cydia database cache is out of sync with your updated package indices. Re-run your localized database indexing core utility ./Packages.sh and execution tool ./update.sh, then refresh sources directly within Cydia.

❌ Error: 404 Not Found on GitHub Pages

Verify your remote deployment targets. Navigate to your repository settings on GitHub Web, go to Pages, and ensure the deployment source points to your main branch at the / (root) directory pathway.
